# The Frontier Gazette — shared edition

This repository contains the read-only public edition of The Frontier Gazette. It includes the current published reading snapshot and static interface only. The private database, OpenAI key, transcripts, saved items, questions, and personal instructions are not included.

Public listings refresh approximately every 90 minutes through GitHub Actions. Refreshes fetch publisher metadata only, preserve existing analyses, and retain previous captures when a source fails. GitHub may delay scheduled runs.
